# GlamAura Salon and Spa Management System

A desktop-based Salon and Spa Management System developed using Python and SQL Server.

## Project Overview

GlamAura Salon and Spa Management System is designed to manage the daily operations of a salon and spa. It provides a simple desktop interface for managing customers, employees, services, products, appointments, billing, product sales, and memberships.

## Technologies Used

- Python
- Tkinter
- SQL Server
- SSMS
- PyODBC

## Features

- User Login
- Customer Management
- Employee Management
- Service Management
- Product Management
- Appointment Management
- Billing
- Product Sales
- Membership Management
- SQL Server Database Integration

## Project Structure

The project is divided into separate Python modules for different salon management operations.

## Database

The system uses SQL Server as the backend database and connects to the database using PyODBC.
